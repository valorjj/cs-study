# 설계 스펙 — FlowPlayer 크게 보기 + 엣지 애니메이션 정돈

> 작성일: 2026-07-27 · 상태: 승인됨(브레인스토밍)
> 선행: 가이드 v2 Phase 1(SHIPPED, `FlowPlayer.tsx`).

## 0. 한 줄 목표
FlowPlayer가 인라인에서 작아 점선 엣지 애니메이션이 산만한 문제를, **전체화면 오버레이 "크게 보기"** + **엣지 애니메이션 정돈(느리게·부드럽게·reduced-motion 존중)**으로 해결한다.

## 1. 확정 결정
1. **크게 보기 = 전체화면 오버레이**(A안). `fp-bar`에 토글 버튼. 열면 뷰포트 전체 모달로 큰 플레이어, `Esc`/`✕ 닫기`로 복귀. **재생 상태·현재 스텝 유지**(동일 컴포넌트 인스턴스).
2. **엣지 정돈**: 행진 속도 0.7s→~2s, 선 얇게(2→1.5)·불투명도↓(.9→.55)·점선 간격↑, `prefers-reduced-motion: reduce`면 행진 정지(정적 점선).

## 2. 범위
`FlowPlayer.tsx` + `FlowPlayer.css` + `FlowPlayer.test.tsx`만. **흐름 데이터·GuideView·types 불변.**

## 3. 동작 상세
- 상태 `expanded: boolean`(초기 false). 토글 버튼 라벨: 축소 시 `⛶ 크게 보기`, 확대 시 `✕ 닫기`.
- 확대 시 루트에 클래스(`flow-player--expanded`) 부여 → CSS로 `position: fixed; inset: 0; z-index: 높게; 배경 딤`, 내부 카드 중앙·큰 여백, 노드/폰트 키움. 축소 시 원래 인라인.
- **엣지 재측정**: 확대/축소로 레이아웃이 바뀌므로 `expanded` 변경 시 노드 위치를 다시 측정한다(기존 ref 측정 로직 재사용 — `expanded`를 측정 트리거에 포함). 기존 `ResizeObserver`도 유지.
- `Esc` 키로 닫기(확대 상태에서만 리스너 활성, cleanup 필수).
- 재생/스텝/이전·다음·처음은 확대·축소와 무관하게 그대로 동작(상태 공유).
- 접근성: 오버레이는 `role="dialog"` + `aria-modal="true"`, 열릴 때 닫기 버튼에 포커스(선택). reduced-motion 존중.

## 4. 테스트 (jsdom+RTL)
- 기존 5개 테스트 유지(스텝/재생/카운터).
- 추가: `크게 보기` 클릭 → 루트에 `flow-player--expanded` 클래스(또는 `role="dialog"` 등장) + 버튼 라벨이 `닫기`로 바뀜; 다시 클릭 or `Esc`(keydown) → 축소(클래스 제거/버튼 `크게 보기`). 확대 중에도 카운터/활성 노드 로직 유지.
- 지오메트리(엣지 좌표)는 jsdom 0이라 검증 안 함(크래시 없음만).
